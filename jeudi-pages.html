Régles du jeu

Mode Solo : Excurtion

Le Mode Solo vous permet de developper vos differents personnages dans le jeu, Il est conseillé pour une meilleure prise en mains du jeu. Il s'agit d'atteindre de nouveaux objectifs tout en decouvrant les différentes facultés de vos personnages.


Mode Multijoueurs

Affrontez vos amis ou lancez-vous au combat en affrontant de nombreux adversaires en ligne. Le Mode Multijoueurs offre aussi la possibilité de former vos équipes, accomplissez des missions, jouer en équipe sur plusieurs Maps, faite vous des alliés et participez au événements hebdomadaire afin de gagner de nombreux lots.


Mode Aventure

Le Mode Aventure vous place au centre du jeu avec le personnage Terry Moussavou. A travers ce personnage, exploirez l"histoire du jeu et atteignez les objectifs de mission pour avencer dans l'histoire. Le mode Aventure vous permet de jouer hors connexion.
