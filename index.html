Les bases de la programmation WEB

Le langage HTML

XHTML 1.0, est une reformulation de HTML en une application XML et trois DTDs (Document Type Definition)correspondant à celles définies par HTML 4.
La compatibilité avec les agents utilisateurs (les "clients") HTML actuels est possible en suivant un ensemble raisonnable de règles.
La sémantique des éléments et de leurs attributs sont définis dans la recommandation W3C pour le HTML. La norme actuelle est XHTML 1.1

Comment créer un lien de téléchargement de fichier ( pdf, audio, vidéo, etc...)

Pour créer un lien de téléchargement il nous faudra utiliser l'élément "a" et son attribut "href"
Sans oublier la valeur qui est le nom du document a télécharger se trouvant dans notre dossier. C'est aussi avec ce meme élement que nous pouvons
créer des liens vers d'autres pages de notre site ou encore vers des sites externes en utilisant l'adresse URL du site ou nous voulons rédiriger la personne
